In this short quick tip post I will basically just give you a quick setup guide that showcase how to set up and connect
to a PostgreSQL database using docker. I will also showcase how you can create a database from a 
sql dump and also connect to that database using a shell inside the docker container. 

## Create the database

Demo database:
[Flight data demo db (postgrespro.com)](https://postgrespro.com/community/demodb)

## Create Volume
```bash
docker volume create flight-data-db
```

## Start container
```bash
docker run --name postgres-db -p 5432:5432 -v flight-data-db:/var/lib/postgresql/data -e POSTGRES_PASSWORD=pwd12345. -d postgres
```

## Copy backup file to container
```bash
docker cp {path_to_file}\demo-small-en-20170815.sql postgres-db:/home/
```

## Get shell inside container
```bash
docker exec -it postgres-db sh
```

## Restore db from .sql file this will create a demo db
```bash
psql -U postgres -f /home/demo-small-en-20170815.sql
```

## Connect to postgres db
```bash
psql -U postgres
// Connect to new db 
\c demo 
// List all tables
\dt 
```
